API Endpoints

Blocking Operations
GET /api/blocking/users - Get all users (blocking)
POST /api/blocking/users - Create user (blocking)
PUT /api/blocking/users/{id} - Update user (blocking)
DELETE /api/blocking/users/{id} - Delete user (blocking)
GET /api/blocking/products - Get all products (blocking)
POST /api/blocking/products - Create product (blocking)


Non-Blocking Operations
GET /api/non-blocking/users - Get all users (non-blocking)
POST /api/non-blocking/users - Create user (non-blocking)
PUT /api/non-blocking/users/{id} - Update user (non-blocking)
DELETE /api/non-blocking/users/{id} - Delete user (non-blocking)
GET /api/non-blocking/products - Get all products (non-blocking)
POST /api/non-blocking/products - Create product (non-blocking)


File Operations
POST /api/file/blocking/write - Write file (blocking)
POST /api/file/non-blocking/write - Write file (non-blocking)
GET /api/file/blocking/read/{fileName} - Read file (blocking)
GET /api/file/non-blocking/read/{fileName} - Read file (non-blocking)

Performance Metrics
Each API response includes performance metrics:

operationType: Type of operation performed
executionTime: Time taken in milliseconds
recordsProcessed: Number of records processed
threadName: Name of the thread that processed the request
timestamp: Timestamp of the operation
